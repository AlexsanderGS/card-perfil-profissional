# 💼 Card Profissional

Projeto de um card de perfil profissional desenvolvido com foco em prática de HTML, CSS e JavaScript, incluindo responsividade e suporte a tema claro/escuro.

## 🚀 Funcionalidades

- ✅ Layout responsivo (Mobile First)
- ✅ Alternância entre tema claro e escuro
- ✅ Estrutura semântica em HTML
- ✅ Organização de CSS com separação por responsabilidade
- ✅ Uso de variáveis CSS para controle de tema
- ✅ Botões com links para redes sociais

---

## 🛠️ Tecnologias utilizadas

- HTML5  
- CSS3 (Flexbox, variáveis CSS)  
- JavaScript (DOM, eventos, classList)

## 🎨 Temas

O projeto possui dois temas:

- 🌞 Tema claro (padrão)
- 🌙 Tema escuro

A troca é feita através de um botão, utilizando:

- `classList.toggle()` no JavaScript
- sobrescrita de variáveis CSS no `.dark-theme`

---

## 💡 Aprendizados

Durante o desenvolvimento deste projeto, foram praticados:

- Estruturação de layout com Flexbox
- Organização de CSS em arquivos separados
- Uso de variáveis CSS para temas
- Manipulação do DOM com JavaScript
- Controle de estado com classes
- Boas práticas de responsividade
